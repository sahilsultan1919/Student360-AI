# Student360 AI — MVP

## 1. Student Category

For Version 1, Student360 AI will support:

- College Students

Target users:
- BTech students
- Undergraduate students

## 2. Input Data

The student will enter:

- Name
- Semester
- CGPA
- Attendance Percentage
- Internal Marks
- Assignment Score
- Quiz Score
- Study Hours per Day
- Number of Backlogs
- Technical Skill Level
- Career Goal

## 3. Prediction

The system will analyze the student's data and provide:

1. Predicted Performance
2. Academic Risk Level
3. Strong Areas
4. Weak Areas

## 4. Recommendation

Based on the student's performance, the system will provide:

- Areas that need improvement
- Study recommendations
- Suggested study hours
- Subject improvement suggestions
- Basic career/skill recommendations

## 5. MVP Goal

The first version of Student360 AI should follow this process:

Student enters information
        ↓
System analyzes information
        ↓
ML model predicts performance
        ↓
System identifies strengths and weaknesses
        ↓
System provides personalized recommendations
