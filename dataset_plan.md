# Student360 AI — Dataset Plan

## Purpose

The dataset will be used to train a machine learning model
that predicts student academic performance.

## Student Features

Each student record will contain:

1. Semester
2. CGPA
3. Attendance Percentage
4. Internal Marks
5. Assignment Score
6. Quiz Score
7. Study Hours Per Day
8. Number of Backlogs
9. Technical Skill Level
10. Career Goal

## Target

The ML model will predict:

- Final Performance Score
- Academic Risk Level

## Example Record

Semester: 4
CGPA: 7.2
Attendance: 82
Internal Marks: 74
Assignment Score: 85
Quiz Score: 70
Study Hours Per Day: 3
Backlogs: 1
Technical Skill Level: 2
Career Goal: AI/ML

Expected Performance: 76
Risk Level: Medium

## Important

The dataset must contain many student records.

The input features will be used by the ML model
to learn patterns related to academic performance.

Synthetic data may be used for the first prototype,
but it must be clearly identified as synthetic data.
